Talea / Squarespace and Wix alternative

A Squarespace and Wix alternative you host yourself

Talea is a website builder you run on your own server, with no monthly platform fee. Its website import reads a Wix or Squarespace site by its address and rebuilds the pages, because neither service lets you move the finished site to another server. The design is not copied, and you take over the upkeep that the hosted service did for you.

What Squarespace exports

Squarespace's export help page describes an XML file in WordPress format. It covers layout pages, one blog page with its posts, text and image blocks, and galleries. It leaves out:

  • album, cover, index, info, calendar, portfolio and store pages
  • page-specific headers, footers and sidebars, and any blog beyond the first
  • dropdowns, audio, product and video blocks
  • drafts, style settings and custom CSS

The site must be public to export, a trial site cannot be exported, and images may not come along.

Bringing the pages into Talea

Talea's website import works from the public address, so it does not depend on what an export file contains. It handles sites built on Wix, Squarespace, Webnode, Jimdo, Joomla, Drupal and WordPress.

  1. Install Talea and enter the address of the old site.
  2. The import finds the pages through the sitemap or by crawling, and takes the main content of each.
  3. It turns that content into builder pages, brings the images into Media and turns blog-like addresses into news items.
  4. Pages are created hidden and outside the menu. You review them before anything goes live.
  5. Old addresses redirect to the new ones.

The design is not copied. The imported pages take the design system of your Talea site, so expect to choose one of the 14 looks, try it on the pages, and adjust. Talea also reads WordPress export files. Whether a Squarespace export file imports cleanly that way has not been tested here, so check the result if you try it.

A monthly fee or a server

Both are real costs. A hosted plan includes hosting, updates and support. With Talea you pay for a server and a domain, and either you do the upkeep or you ask someone to. If nobody can do the upkeep, the fee of a hosted plan pays for that work. If someone can, the fee for the platform goes away.

What Squarespace and Wix do better

  • Nothing to run yourself and no server to choose.
  • Support from the vendor is included.
  • Wix lists bookings as a feature that works out of the box.
  • If you sell online through your hosted builder today, check that you can replace that part first. Talea has no checkout.

When to choose something else

  • You have nobody to run a server and no one to ask. A hosted plan is the better fit.
  • You need checkout and payments on the site.
  • Your host cannot run Docker, which Talea needs.
  • You rely on page types that only the old service offers, such as a store or a portfolio, and Talea has no counterpart.

Questions people ask

Can I export my Squarespace site?+

Squarespace exports an XML file in WordPress format. It covers layout pages, one blog, text and image blocks and galleries, and leaves out several page types, drafts, style settings and custom CSS. The site must be public, and a trial site cannot be exported.

Is Wix self-hosted?+

No. Wix states that a Wix site must be hosted and operated on Wix's servers, and embedding it elsewhere is not supported.

How do I leave Wix?+

You cannot move the site itself to another server. Talea's website import reads the public site by its address, rebuilds the pages, brings the images into Media and redirects the old addresses. You then choose a look for the design.

Is there a Squarespace alternative with no monthly fee?+

Talea is free software under GPL-2.0-or-later, so the software has no fee. You pay for the server and the domain, and the upkeep is yours or that of the person you ask.

Does my design come along?+

No. The import takes the content of the pages. They use the design system of your Talea site.

Does Talea have bookings like Wix?+

Yes. Visitors pick a service, a person or anyone, a day and a free time, and get a confirmation by e-mail with a cancel link. Payments and deposits are not included.
