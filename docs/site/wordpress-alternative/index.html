Talea / WordPress alternative

A self-hosted WordPress alternative for small businesses

Talea is a self-hosted alternative to WordPress for a small business that wants forms, bookings and a newsletter without choosing plugins. WordPress remains the better choice if you want its plugin and theme choice, hosting on ordinary PHP hosting, or a developer who already knows it. This guide compares what each one asks of you.

Who updates what

WordPress applies minor core updates automatically by default. Major core updates are automatic on fresh installs from version 5.6, and plugins and themes update automatically only in special cases. Every plugin you add is one more thing to keep current.

Talea has no plugins with updates of their own. An update is a new container image, and the person who runs the server pulls it. The owner of the business never updates anything. Because there is no updater in the admin, this needs Docker and someone comfortable with it.

Moving from WordPress to Talea

Talea reads WordPress export files (WXR), including Gutenberg blocks. For a site without an export file, the website import takes the address of the site, finds its pages through the sitemap or by crawling, takes the main content and turns it into builder pages. Images come into Media, and blog-like addresses become news items.

Imported pages arrive hidden and outside the menu, so nothing goes live before you have checked it. Old addresses redirect to the new ones. The design is not copied. The pages take the design system of your Talea site, and you can try one of the 14 looks on them before you apply it.

When to stay on WordPress

  • Your site depends on a particular plugin or theme that Talea has no counterpart for.
  • You have a developer or an agency that works in WordPress and you want to keep that relationship.
  • You can only use shared PHP hosting, because Talea needs Docker.
  • You need checkout and payments on the site, which Talea does not include.

What Talea does not do

  • No checkout and no payments. Products can be shown with prices and variants, and order enquiries arrive from a basket.
  • No large plugin ecosystem and no marketplace of thousands of templates.
  • No updater on shared hosting. Updates mean pulling a new image.
  • The admin comes in English, German and Czech.

Questions people ask

Is Talea a WordPress replacement?+

Talea can replace a WordPress site that is mostly pages, news, forms, bookings and a newsletter. It does not replace WordPress where a site depends on particular plugins, a shop with checkout, or hosting without Docker.

Can I import my WordPress site into Talea?+

Yes. Talea reads WordPress export files, including Gutenberg blocks, and its website import can also read a WordPress site by its address when you have no export file. Pages arrive hidden and old addresses redirect to the new ones.

Do I need plugins for forms and bookings in Talea?+

No. Forms, bookings and a newsletter are built in, so there are no plugins to choose or to update.

Does Talea run on the same hosting as WordPress?+

Not necessarily. WordPress needs PHP 8.3 or newer and MariaDB 10.11 or newer or MySQL 8.0 or newer on Apache or Nginx. Talea runs as a container with Docker, so a host without Docker is not a fit.

Is WordPress free?+

WordPress is released under GPLv2 or later. As with Talea, you provide the server and the domain.
