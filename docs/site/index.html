Getting started

Set up once, in minutes.

Talea runs on any server that can run Docker. If that sentence means nothing to you, it will to your web person – it’s three lines for them.

curl -O https://raw.githubusercontent.com/czepter/taleacms/main/docker-compose.yaml
echo "TALEA_DB_PASSWORD=$(openssl rand -hex 16)" > .env
docker compose up -d
# open http://localhost:8080 – the setup takes it from there
For the technical folks
  • Plain PHP 8.5, no framework, no build step. GPL-2.0-or-later.
  • MySQL 8, MariaDB 11.4+, PostgreSQL 18 or SQLite.
  • One container per site; updates are a new image, signed and multi-arch.
  • Built-in MCP server: whatever the editor can do, an AI assistant can do too.
  • Clean HTML output, no third-party scripts or fonts. Read more on GitHub.
