AI as a first-class user

Tell your assistant what you want. It builds a draft. You publish.

  • Full parity over MCPPages, builder, design system, media, collections, forms, menus, redirects, news, settings: 173 tools, the same validation and permissions as the editor.
  • Drafts only, always undoableEverything an assistant writes lands as a draft with a signed preview link. A whole session can be rolled back in one click.
  • Built into the admin, tooA first-run wizard plans your site from a few answers, and the builder’s Ask box edits the page in plain words – with your own API key.
  • Guardrails, not vibesNo invented reviews or prices: placeholders are flagged before you publish. Model output passes the same sanitizer as everything else.

Visual builder

The canvas is the real page.

Drag, resize and space things directly on the page. What comes out reads like hand-written HTML.

  • One element, one tagNo wrapper soup. Page CSS contains only what the page uses, in cascade layers.
  • Compose on a 12-column gridPlace and overlap elements in layers; tablet and phone stack them in order.
  • Desktop, tablet, phone, hoverStyle each state separately. Gestures snap to your spacing tokens.
  • Versions, comments, share linksDrafts autosave, publishing keeps the last 20 versions.

Design system

Change one colour. The whole site follows.

  • Tokens all the way downFluid type and spacing with clamp(), tints in OKLCH, dark mode built in.
  • Contrast checked for youWCAG contrast is computed for every colour pair, light and dark.
  • 14 looks, 28 self-hosted fontsTry a look on your real site before you apply it. No font CDN, ever.

Self-host

One container. Your server.

No phone-home, no in-app updater, no third-party scripts or fonts. An update is a new image; migrations run before the site starts.

  • Signed multi-arch imagesamd64 and arm64 on GHCR, signed with cosign.
  • Pick your databaseThe same code on all four, through a small dialect layer. SQLite for a small site with no server at all.

How it is built

Boring tech, on purpose.

Plain PHP

No framework, no ORM, no DI container, no build step, no npm in the product.

Clean output

Tests enforce that no style or script ships for markup nobody renders.

Web platform 2026

Cascade layers, container queries, :has(), Popover API, <dialog>, view transitions. No polyfills.

Privacy by default

No CDN, no foreign fonts, no tracking cookies. UUIDs at every boundary.

Tested for real

Unit, integration and whole installed sites over HTTP on MySQL, PostgreSQL and SQLite, plus a browser walk.

English everywhere

Code, docs and tests in English. The admin speaks English, German and Czech.
