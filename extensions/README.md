# extensions/

Add-ons for Talea live here, one folder per add-on (`extensions/<slug>/` with `extension.json`). Copy an add-on in,
then switch it on in the administration under **Add-ons** – only code you trust: an add-on runs with the same rights as
Talea. Updates of Talea never touch this folder.

For developers: [docs/EXTENSIONS.md](../docs/EXTENSIONS.md), example in `docs/examples/extensions/hello/`.
